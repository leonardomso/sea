# Unity client

The client targets Unity `6000.3.23f1` on Apple Silicon, using URP and an orthographic 2.5D presentation. The project supports WebGL and macOS builds. The editor runs on the host machine; the local backend and admin services remain separate.

The SpacetimeDB Unity SDK is based on upstream `v2.8.3`, matching the CLI used to generate `Assets/Generated/SpacetimeDB`. It is vendored under `packages/spacetimedb-unity` with one compatibility import for Unity 6 WebGL compilation; newer unreleased upstream branches change the client API and are not used.

## Local validation

The first scene is generated by the editor method below so it is reproducible and does not depend on hand-edited scene YAML:

```bash
unity run --project apps/game-unity -- -batchmode -nographics -executeMethod Sea.Editor.SeaSceneBuilder.CreateMainScene -quit
```

The generated scene displays a connection overlay, creates the first tropical map from subscribed server rows, and connects anonymously to `http://127.0.0.1:3000`, database `sea-local`.

The first playable controls are intentionally small:

- Click open water to issue a server-authoritative `move_to` command.
- Click an enemy or press `Tab` to issue `select_target`.
- Press `E` to explicitly issue `engage`; cannon fire then resolves on the server.
- Press `U` to request the first cannon upgrade when enough gold is available.
