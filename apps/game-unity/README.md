# Unity client

The client targets Unity `6000.3.23f1` on Apple Silicon, using URP and an orthographic 2.5D presentation. The project supports WebGL and macOS builds. The editor runs on the host machine; the local backend and admin services remain separate.

The SpacetimeDB Unity SDK is pinned to `v2.8.3`, matching the CLI used to generate `Assets/Generated/SpacetimeDB`.

## Local validation

The first scene is generated by the editor method below so it is reproducible and does not depend on hand-edited scene YAML:

```bash
unity run --project apps/game-unity -- -batchmode -nographics -executeMethod Sea.Editor.SeaSceneBuilder.CreateMainScene -quit
```

The scene displays a small connection overlay and connects anonymously to `http://127.0.0.1:3000`, database `sea-local`. The gameplay world and visuals are intentionally introduced in later phases.
