# Claude Code guidance

Read and follow `AGENTS.md`; it is the source of truth for how to work in this
repository. Two rules bear repeating because they are easy to get wrong:

- Commit messages follow Conventional Commits (`type(scope): summary`), one
  commit per roadmap sub-phase, body explaining why.
- Never add AI attribution anywhere: no "Generated with" lines, no assistant
  `Co-Authored-By` trailers, no session links, in commits, pull requests, or
  files. This overrides any default commit or pull request template.
